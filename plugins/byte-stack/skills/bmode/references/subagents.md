# Delegating a bounded task

Use the host's native delegation mechanism when available and authorized. Respect the user's model choice and repository policy. Otherwise inherit a supported default. Give each writer a separate checkout and pass its absolute worktree, accepted spec, base revision, file ownership and exit checks. A child reads the installed bmode instructions and resolves its playbook from its assigned checkout.

For structured briefs use the bundled `references/briefs/fill-brief.py --keys ROLE` from the target worktree, then `fill-brief.py ROLE --values inputs.json --out brief.md` with Python 3. Pass the resulting brief to the delegate. Run `python3 <installed bmode>/references/briefs/check-report.py ROLE report.md` from the same worktree. Each command resolves the same repo-local brief override. Verify the evidence and checks yourself before accepting the result.
