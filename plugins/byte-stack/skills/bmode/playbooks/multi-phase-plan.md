# Multi phase plan

Use when: Design a multi-step change before implementation.

State the goal, inputs, constraints and open decisions. Inspect the owning source. Split the work into vertical slices with dependencies and observable exit criteria. Identify irreversible steps and obtain required approval before building.

Record checkboxes for actionable slices and a verification command for each phase. Keep working plans in the location prescribed by the repo and commit completed phases according to its convention.
